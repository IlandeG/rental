## אוטומציה שבועית להוספת שורות לטבלה

קובץ `WeeklyRowsAutomation.gs` הוא Google Apps Script שמוסיף בכל שבוע 5 שורות חדשות בראש הטבלה, ממזג את עמודת ה-Week ומציב את טווח התאריכים של השבוע הקרוב (לדוגמה: `10-16.5` או `26.4-2.5` כשהשבוע חוצה חודשים).

### התקנה
1. פתחו את הגיליון ב-Google Sheets.
2. תפריט **Extensions → Apps Script**.
3. הדביקו את התוכן של `WeeklyRowsAutomation.gs` לעורך.
4. עדכנו את הקבועים בראש הקובץ במידת הצורך:
   - `SHEET_NAME` - שם הגיליון.
   - `HEADER_ROWS` - מספר שורות הכותרת (ברירת מחדל 2).
   - `ROWS_PER_WEEK` - כמה שורות מוסיפים בכל שבוע (ברירת מחדל 5).
   - `TOTAL_COLUMNS` - מספר העמודות בטבלה (ברירת מחדל 6).
5. שמרו והריצו פעם אחת את `installWeeklyTrigger` כדי לקבוע הפעלה אוטומטית כל יום ראשון בבוקר.
6. לבדיקה ידנית: הריצו את `addWeeklyRows`.
